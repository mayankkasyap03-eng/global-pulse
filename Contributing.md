# Contributing to Global Pulse

Thank you for contributing!

## How to Contribute
1. Fork this repository
2. Create a new branch for your changes
3. Add or update content in the correct folder
4. Submit a Pull Request with clear description

## Content Guidelines
- Use verified and credible sources only
- Always add date + source link  
- Stay neutral and factual
- Clearly mark any paid content
- No spam or unverified claims

Together we can build a valuable resource for the world.
